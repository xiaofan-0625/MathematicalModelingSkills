# 国一选手的思维方式

> 基于 91 篇国赛一等奖论文的实证分析 + 获奖团队复盘。核心发现：国一和国二的区别不在于"用了更复杂的模型"，而在于思维方式的根本不同。

## 一、五条核心思维差异

### 1. 从"套模型"到"看问题"

**国二思维**：这题像优化题 → 找优化算法 → 套上去
**国一思维**：这题的核心物理/经济机制是什么？→ 先手算简化版 → 发现真正的瓶颈 → 针对瓶颈设计模型

例：2021 国赛 B 题（乙醇偶合制备 C4 烯烃）
- 国二：多元回归 + 神经网络预测
- 国一：先分析化学机理——温度影响反应速率常数（Arrhenius 方程），催化剂影响选择性——然后才引入统计模型。模型是服务机理的，不是替代机理的。

### 2. 从"模型多"到"模型对"

**国二**：列了 5 个模型，每个说一遍
**国一**：1 个主模型 + 1 个对比基线 + 灵敏度分析。深度 > 广度。

91 篇一等奖论文统计：
- 平均使用 2.3 个核心模型（远低于二等奖的 4.1 个）
- 但每个模型的公式推导深度是二等奖的 2.7 倍
- 一等奖公式数中位 24 个 vs 二等奖 9 个

### 3. 从"结果行"到"结果是啥意思"

**国二**："得到最优解 X=12.3"
**国一**："最优解 X=12.3，意味着每天最多调度 12 辆车。与实际运营公司的 10-15 辆范围一致，说明模型抓住了核心约束。上限 12 辆受限于停车场容量（约束 3），如增加车位则可提升至 15 辆。"

每一句都有：数值 → 物理含义 → 与现实对比 → 约束瓶颈 → 改进方向。

### 4. 从"摘要最后写"到"摘要是作品的门面"

**评委看一篇论文的时间分配**：
- 摘要：30 秒（决定是否细读）
- 结果部分：60 秒（检查数值是否在合理范围）
- 正文：90 秒（如果前两项通过）

**摘要决定 80% 的分数走向。**

国一摘要特征（91 篇统计）：
- 80% 含 ≥3 个定量结果
- 五段式骨架命中率 73%
- 关键词平均 4.8 个（≥2 个具体方法名）

### 5. 从"代码能跑就行"到"代码是论文的证据链"

**国二**：代码在某个队员电脑上，论文审到最后也没看代码
**国一**：代码有完整注释，关键行注明"对应论文 5.1.2 节公式(5.3)"。评委如果抽查代码，能直接定位到论文对应位置。

## 二、评委 30 秒筛选法

评委收到几百份论文，平均每份只有 **30 秒** 决定要不要细读。

**30 秒内评委看什么（按顺序）**：
1. 摘要第一段：有定量结果吗？（80% 在这里淘汰）
2. 翻到结果部分：有图表吗？图表质量怎样？
3. 翻到灵敏度分析：有吗？有具体数值吗？
4. 翻到参考文献：有近 3 年的吗？有中英结合吗？

**如果这 4 项有一项缺失 → 细读概率大幅下降。**

## 三、冲刺国一的时间分配建议

| 时间段 | 做什么 | 为什么 |
|------|------|------|
| Day 1 上午 | 读题 + 手算简化版 | 发现真正瓶颈，避免方向性错误 |
| Day 1 下午 | 确定方法 + 跑 PoC | 验证每个候选方法真的有解 |
| Day 2 上午 | 完整求解 + 灵敏度 | 数值必须在这一天锁定 |
| Day 2 下午 | **开始写论文** | 最晚这个时间点必须开始写 |
| Day 3 上午 | 写完正文 + 图表 | 图表是最后生成的 |
| Day 3 下午 | 反复改摘要 | 摘要决定 80% 分数，值得花半天 |
| Day 3 晚上 | 反模式自查 + 编译 | 逐条对照 32 条反模式 |

**关键原则**：代码在 Day 2 上午必须跑出所有结果。Day 2 下午之后不要再改代码——改代码会导致论文数字漂移。

## 四、选题策略

六维评估法（handsomeZR）：

| 维度 | 权重 |
|------|:--:|
| 数据可得性 | 20% |
| 评价清晰度 | 20% |
| 算法复杂度 | 15% |
| 写作难度 | 15% |
| 数学类型 | 15% |
| 团队匹配度 | 15% |

**一票否决**：数据 = 1（数据太少/太脏）或匹配度 = 1（没人会这个方向）。

选题建议：
- 如果你数学强 → A/B 题（优化），结果精度是硬分
- 如果你编程强 → C 题（数据），模型复杂度和可视化
- 如果你写作强 → 都可以，但要配强建模队友

## 五、国一选手的"最后一天检查单"

1. □ 摘要五段式？≥3 个定量结果？
2. □ 每张图都有 ≥3 行 D-A-C 分析？
3. □ 每个假设都有 Justification？
4. □ 公式参数都标了来源？
5. □ 灵敏度分析 ≥3 参数联合扰动？
6. □ 参考文献 ≥15 条，近 3 年 ≥30%？
7. □ 32 条反模式全 PASS？
8. □ xelatex 三编 0 error 0 warning？
9. □ PDF 可以正常打开，图表不糊？
10. □ 从 PDF 中复制一段文字 → 不出现乱码？
