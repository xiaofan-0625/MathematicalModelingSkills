# 优化类问题冲刺国一方法论

> 适用：国赛 A/B 题、物理/工程优化题。核心目标：结果精度逼近标准答案。

## 一、国赛优化题的评分逻辑

**A/B 题和 C 题的评分体系完全不同：**

| 维度 | C 题（数据题） | A/B 题（优化题） |
|------|:--:|:--:|
| 模型复杂度 | 30% | 15% |
| 结果精度 | 15% | **45%** |
| 论文写作 | 40% | 25% |
| 创新性 | 15% | 15% |

**核心结论：A/B 题的结果精度占 45%。你的数值和标准答案差 5% 以上，直接掉档。**

评委手上有一张标准答案表，包含关键参数的预期范围。他们会先看你的结果在不在范围内，再决定是否细读论文。

## 二、国一选手的思考路径

### 2.1 拿到题目的前 30 分钟

**不做的事**：查书、搜论文、开代码
**做的事**：手算一个简化版

```
例：2023 国赛 A 题（定日镜场优化）
- 题目给了一堆参数和约束
- 国一选手第一步：把圆形场地简化成 1 个镜子
- 手算：1 个镜子在正午 12 点的光路
- 验证：cos 值、反射角、阴影遮挡
- 发现：遮挡是主要限制因素 → 后续建模重点放在遮挡模型上
```

**核心原则**：用最简单的假设跑通整个求解链路，发现真正的瓶颈。

### 2.2 建模阶段的"命名变体"策略

**二等奖选手**："我们采用遗传算法求解"
**国一选手**："本文提出**自适应罚函数-多岛遗传算法（AP-MIGA）**"

区别：
- 命名变体 ≠ 造名字。你必须真的改进了算法
- 至少改动一个核心算子（选择/交叉/变异/约束处理）
- 说明：为什么标准算法不够用？你的改进解决了什么问题？

**常见改进方向**：
| 标准算法 | 常见缺陷 | 改进方向 |
|---------|---------|---------|
| GA | 早熟收敛 | 自适应交叉概率 + 小生境技术 |
| SA | 退火速度难调 | 自适应降温速率（根据当前最优值变化率） |
| PSO | 局部最优 | 多群协同 + 扰动重置 |
| LP | 约束非线性 | 分段线性化 + 迭代修正 |
| DE | 参数敏感 | 自适应 F/CR 策略 |

### 2.3 求解阶段的"多起点 + 多方法"策略

**单一算法跑一次 ≈ 彩票**

国一选手的标准操作：
```
1. 多起点：随机生成 50-100 个初始点，独立运行
2. 多方法：GA + SA + PSO 各跑一遍
3. 交叉验证：三种方法的最优解偏差 < 1% → 可信
4. 局部精修：把全局最优解作为初始点，用梯度下降/模式搜索精修
5. 结果汇总：取所有可行解中目标函数最优者
```

**为什么这样做**：
- 如果三种方法得到相近结果 → 大概率是全局最优
- 如果偏差 > 5% → 至少有一种方法陷入了局部最优
- 局部精修能把 "0.9 × 全局最优" 提升到 "0.99 × 全局最优"

### 2.4 约束处理的"先松后紧"策略

```
第一轮：放松约束 → 求得理想上界
第二轮：加入全部约束 → 求得可行解
第三轮：收紧关键约束 → 观察哪些约束是瓶颈
```

输出格式：
```
无约束理论最优：XXX
全约束可行最优：YYY（Δ = X%）
瓶颈约束：约束 3（占 Δ 的 Z%）
改进方向：如果放宽约束 3...
```

## 三、最关键的技术：参数灵敏度与校准

### 3.1 结果校准（逼近标准答案）

**场景**：你算出最优利润 = 8,723,456 元，但不知道是不是标准答案

**校准方法**：
1. 找几个极端参数组合，手算出理论值
2. 对比你的模型输出 vs 手算值 → 偏差 < 0.1% → 模型正确
3. 用文献中已知的 benchmark 验证
4. 如果题目给了验证集/测试用例 → 必须通过

### 3.2 灵敏度分析（告诉评委你的模型可信）

**二等奖**："±20% 参数扰动，结果稳定"
**国一**：

```
全局灵敏度分析（Sobol 方法）：
  参数 α: 一阶灵敏度指数 S1 = 0.62（主导）
  参数 β: S1 = 0.18（次要）
  参数 γ: S1 = 0.05（不敏感）
  交互效应 α×β: S2 = 0.08

结论：模型对 α 最敏感，α 的±10% 变化导致结果 ±6.3% 波动
稳健区间：当 α ∈ [0.35, 0.42], β ∈ [0.18, 0.25] 时，最优解变化 < 3%
```

### 3.3 LHS（拉丁超立方抽样）— 国一标配

```python
from scipy.stats import qmc
sampler = qmc.LatinHypercube(d=3)  # 3 个参数
sample = sampler.random(n=100)     # 100 个采样点
# 将 [0,1] 映射到实际参数范围
params = qmc.scale(sample, lower_bounds, upper_bounds)
```

LHS 比随机抽样效率高 10-100 倍（相同精度下），是国一论文灵敏度分析的标准配置。

## 四、算法参数调优

### 4.1 不要用默认参数

标准 GA 的默认参数是针对 benchmark 函数调好的，不是针对你的问题。

**调参流程**：
1. 固定其他参数，单个参数做扫描（如交叉概率 0.5-0.95，步长 0.05）
2. 找到最优区间 → 精细扫描（步长 0.01）
3. 交互参数用响应面法（如交叉 vs 变异概率的二维网格）
4. 最终参数在论文中以表格形式给出

### 4.2 参数来源必须有依据

- "种群大小 = 100" → ❌
- "种群大小 = 100，经预实验在 50/100/150/200 中对比确定" → ✅
- "种群大小 = 100，参考文献 [X] 的建议，并结合问题规模调整" → ✅

## 五、代码层面的优化

### 5.1 向量化是关键

```
❌ for i in range(n): result[i] = compute(x[i])
✅ result = compute_vectorized(x)  # numpy 广播
```

对于大规模优化（>10^4 变量），向量化可能是 10-100 倍的速度差异。

### 5.2 早停与缓存

```python
best_fitness = float('inf')
for gen in range(max_gen):
    fitness = evaluate(population)
    if abs(best_fitness - fitness) < 1e-6:  # 收敛
        break
    best_fitness = fitness
    # 每 10 代保存结果，防止崩溃
    if gen % 10 == 0:
        save_checkpoint(population, fitness)
```

### 5.3 并行化

```python
from multiprocessing import Pool
with Pool(8) as pool:
    results = pool.map(run_single_trial, initial_points)
```

多起点优化天然可并行。8 核并行跑 80 次 ≈ 1 次的时间。

## 六、拿到结果的最后一步：回代验证

```
1. 你的最优解是 x* = (0.42, 0.31, 0.27)
2. 代入所有约束：g1(x*) = 0.98 ≥ 0 ✅
                  g2(x*) = 1.52 ≤ 2 ✅
                  g3(x*) = -0.01 ≈ 0 ✅ (在容差内)
3. 回代目标函数：f(x*) = 8,723,456
4. 手动验算简化版：理论值 ≈ 8,700,000 → 偏差 0.27% ✅
5. 结论：最优解可信
```

**不要相信求解器的 `success=True`。必须手动回代验证。**
