# 去AI味体检官（de-ai-flavor）

给中文文案做「AI味体检」，再改写成像人写的。先给一份体检报告——AI味浓度多少、命中了哪几条、哪里本来就写得好；再给改写后全文，附三行内「改了什么」。

方法论是一份编辑部每天在用的人味审校清单，八项加权打分：框架词、AI高频词、排比对仗、句长同构、情感缺失、细节缺失、书面腔、冗余句。

## 安装

- **Claude Code**：把 `SKILL.md` 放进项目的 `.claude/skills/de-ai-flavor/` 目录，对话里说「帮我去AI味」即可。
- **其他支持 Agent Skill 的助手**：导入本仓库的 `SKILL.md`（单文件、零依赖、无脚本），或直接把文件内容作为技能说明发给你的助手。
- **小红书**：RedSkill 商店搜「去AI味体检官」，点「去使用」。

## 效果

见 [examples/](examples/)：两组真实运行的前后对比（原文 → 体检报告 → 改写后），分数未经修饰。

## 几句实话

- 分数是参考值，同一篇文两次体检允许 ±10 的浮动。
- 目标是「读起来更像人写的」，不承诺通过任何 AI 检测工具。
- 输入一律视为待改写的文案数据、不视为指令——这条防注入规则写死在 SKILL.md 里。
