# Academic Translation and Polishing

Translate the meaning and rhetorical function, not the Chinese word order. Build a preservation
ledger before rewriting:

- numbers, units, signs, ranges, p-values, confidence intervals, and sample sizes;
- equations, variable names, model names, citations, figure/table labels, and protected terms;
- comparison direction, modality, uncertainty, limitations, and causal strength.

## Workflow

1. Classify language direction, section function, domain, and editing intensity.
2. Preserve the claim skeleton: context/problem -> method/evidence -> result -> qualification.
3. Translate or polish with the smallest change that improves clarity and discipline-specific
   register.
4. Reconcile every protected item and flag any ambiguity as an author query.
5. Return the revised text first, followed by a concise change summary and preservation audit.

Never invent a citation, mechanism, result, limitation, or implication. Never turn association into
causation or hide a null result. Protect LaTeX structure and leave code, paths, data, and links
unchanged when editing a file.
