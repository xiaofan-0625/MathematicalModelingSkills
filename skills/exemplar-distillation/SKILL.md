# Distill Exemplary Papers

Use exemplary papers as evidence about communication and quality control, never as authority for the current problem's answer.

## Workflow

1. Select examples by relevance and provenance. Record competition, year, problem type, award status if verified, and source quality.
2. Extract patterns into five layers: problem decomposition, model progression, validation design, visual evidence, and paper organization.
3. Separate transferable mechanisms from topic-specific content. Reject distinctive prose, data, figures, parameter values, code, and conclusions.
4. For each candidate pattern record: source location, why it worked, current-project fit, required adaptation, misuse risk, and a test of whether it improves the present work.
5. Compare multiple examples when claiming a recurring pattern. A single paper produces an observation, not a general rule.
6. Write `求解/证据/exemplar_patterns.md` and a short adoption ledger linking each adopted pattern to the current subproblem and verification plan.

## Gate

The gate passes when adopted patterns improve a concrete decision and none is being used as a substitute for problem interpretation, evidence, or validation. Unknown award status and inaccessible passages must remain explicitly unverified.

For competition-paper style, combine the distilled evidence with `national-award-paper-style`; do not copy phrases from the corpus.
